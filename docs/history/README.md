# History

Dated records about this repository: retirement maps, acceptance records,
audits, investigations and review records. They say what was true on their
date. None is an instruction, and none describes how Lab behaves now; for
that, use the [documentation index](../README.md).

Records are kept unchanged. Paths written inside a record are the paths at its
date; several name files that have since moved here or to
[Kybern Workshop](https://github.com/supernovae/kybern-workshop).
