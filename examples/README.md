# Examples

Small, maintained examples of Lab's interfaces. Model projects themselves live
in [Kybern Workshop](https://github.com/supernovae/kybern-workshop) or your own
repository. Outputs and downloads go in the work directory; see
[workspaces](../docs/workspaces.md).

| Example | Shows |
| --- | --- |
| [`build-local-text`](build-local-text/) | [Building a model from your own text](../docs/build.md) |
| [`post-training`](post-training/) | [The stages after it](../docs/post-training.md): instruction tuning, distillation, preference optimization and export |
| [`lab-job-try`](lab-job-try/) | A bounded [lab job](../docs/lab-jobs.md) that runs one try |
| [`hosted-cuda`](hosted-cuda/) | Running on a [hosted GPU](../docs/hosted-environments.md) |
