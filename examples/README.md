# Maintained interface examples

Use [Kybern Workshop](https://github.com/supernovae/kybern-workshop) for editable experiment definitions. `build-local-text` is the starting point for [building a model from your own text](../docs/build.md). The tiny `lab-job-try` and `tiny-campaign` examples are maintained integration fixtures for Lab interfaces, not duplicated scientific experiments. Runtime outputs and downloaded corpora belong in the configured external work directory; see [location controls](../docs/location-runtime-controls.md).
